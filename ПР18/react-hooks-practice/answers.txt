Ответы на вопросы по практической работе 18

1. В чём разница между Link и NavLink в React Router?
Компонент Link просто создаёт ссылку для перехода без перезагрузки страницы.
NavLink - специальная версия Link, которая автоматически применяет CSS-класс "active" (или указанный через className) к ссылке, если текущий URL совпадает с путем в атрибуте "to". Это удобно для стилизации активного пункта меню.

2. Как получить параметры из URL в компоненте?
Для получения динамических параметров из URL (например, ID товара из /products/:id) используется хук useParams(). Он возвращает объект с ключами, соответствующими параметрам в пути маршрута.

3. Что такое программная навигация и как ее реализовать?
Программная навигация - переход между страницами, который происходит не по клику на ссылку, а в результате выполнения кода (например, после отправки формы или нажатия кнопки).
В React Router v6 для этого используется хук useNavigate(). Он возвращает функцию, которую можно вызвать с нужным путем: navigate('/path').

4. Как передать данные между маршрутами?
В React Router v6 данные можно передать через компонент Link (атрибут state) или через программную навигацию (navigate('/path', { state: { data } })). На принимающей стороне эти данные извлекаются с помощью хука useLocation() (location.state).

5. Что делает компонент Routes?
Компонент Routes заменяет собой Switch из старых версий React Router. Он оборачивает все маршруты (Route) и отвечает за то, чтобы отрендерился только тот маршрут, который наилучшим образом совпадает с текущим URL.

6. Как создать защищённый маршрут?
Создаётся компонент-обертка (например, ProtectedRoute), который проверяет наличие прав (например, авторизован ли пользователь). Если пользователь не авторизован, компонент возвращает <Navigate to="/login" replace />. Если авторизован, он рендерит переданный ему дочерний компонент (children).

7. В чём разница между useNavigate и redirect?
useNavigate - хук, который используется внутри React-компонентов для программного перехода (например, в обработчике события).
redirect - функция, которая используется в API данных (loaders/actions) React Router v6.4+ для переадресации до того, как компонент будет отрендерен (например, если данных не существует).
