Ответы на вопросы по практической работе 4

1. Какое основное свойство CSS включает Flexbox и что происходит с дочерними элементами после его применения?
Flexbox включается свойством display: flex у родительского элемента. Такой элемент становится flex-контейнером, а его непосредственные дочерние элементы - flex-элементами. После этого для их расположения можно использовать свойства Flexbox, например flex-direction, justify-content, align-items и flex-wrap.

2. В чем разница между justify-content и align-items? Приведите примеры использования каждого.
justify-content выравнивает и распределяет flex-элементы вдоль главной оси. Например, при flex-direction: row свойство justify-content: center располагает элементы по центру горизонтально.
Может принимать следующие значения:
- flex-start: элементы выравниваются по левой стороне контейнера.
- flex-end: элементы выравниваются по правой стороне контейнера.
- center: элементы выравниваются по центру контейнера.
- space-between: элементы отображаются с одинаковыми отступами между ними.
- space-around: элементы отображаются с одинаковыми отступами вокруг них.
- space-evenly: элементы распределяются так, чтобы все отступы (и между ними, и до краев контейнера) были абсолютно одинаковыми.

align-items выравнивает элементы по поперечной оси. Например, при flex-direction: row свойство align-items: center выравнивает элементы по вертикали.
Может принимать следующие значения:
- flex-start: элементы выравниваются по верхнему краю контейнера.
- flex-end: элементы выравниваются по нижнему краю контейнера.
- center: элементы выравниваются вертикально по центру контейнера.
- baseline: элементы отображаются на базовой линии контейнера.
- stretch: элементы растягиваются, чтобы заполнить контейнер.

3. Что делает свойство flex-direction и какие значения может принимать? Как оно влияет на основную ось?
flex-direction задаёт направление расположения flex-элементов и тем самым определяет направление главной оси.

Основные значения:
- row: элементы размещаются по направлению текста.
- row-reverse: элементы отображаются в обратном порядке к направлению текста.
- column: элементы располагаются сверху вниз.
- column-reverse: элементы располагаются снизу вверх.

При row главная ось горизонтальная, а при column - вертикальная.

4. Объясните значение трех свойств в сокращенной записи flex: 1. Что означают flex-grow, flex-shrink и flex-basis?
Сокращённая запись flex объединяет три свойства:
- flex-grow - коэффициент увеличения элемента при наличии свободного места;
- flex-shrink - коэффициент уменьшения элемента, если места недостаточно;
- flex-basis - исходный размер элемента вдоль главной оси.

Запись flex: 1 - сокращение от flex: 1 1 0%, то есть flex-grow: 1, flex-shrink: 1, flex-basis: 0%. Элемент получает равную долю свободного места с другими такими же элементами. Используется, например, для равного распределения ширины колонок.

5. Как работает свойство flex-wrap и в каких случаях его следует использовать?
flex-wrap определяет, разрешён ли перенос flex-элементов на новую строку или колонку.

Основные значения:
- nowrap - перенос запрещён;
- wrap - элементы могут переноситься;
- wrap-reverse - перенос выполняется в обратном направлении.

Свойство полезно, когда элементов несколько и на маленькой ширине экрана они не должны выходить за пределы контейнера.

6. Чем отличается align-content от align-items и когда применяется каждое из этих свойств?
align-items выравнивает flex-элементы внутри одной flex-линии по поперечной оси.

align-content работает с несколькими flex-линиями, то есть становится заметен при переносе элементов через flex-wrap: wrap. Оно распределяет сами линии внутри контейнера по поперечной оси.

Поэтому align-items используется для выравнивания элементов, а align-content - для распределения нескольких рядов элементов.

7. Как свойство order влияет на отображение элементов и в каких практических ситуациях оно может быть полезно?
order меняет визуальный порядок flex-элементов. Элементы с меньшим значением order располагаются раньше. Значение по умолчанию равно 0.

Свойство может использоваться, когда на разных вариантах макета требуется изменить визуальный порядок блоков без изменения их порядка в HTML.

8. Что такое «осевая линия» (main axis) и поперечная ось (cross axis) в Flexbox и как они связаны с flex-direction?
Главная ось (main axis) - направление, вдоль которого Flexbox в первую очередь размещает элементы. Поперечная ось (cross axis) перпендикулярна главной.

При flex-direction: row главная ось горизонтальная, а поперечная вертикальная.

При flex-direction: column главная ось вертикальная, а поперечная горизонтальная.

По главной оси обычно работает justify-content, а по поперечной - align-items.

9. Как создать адаптивный макет с помощью Flexbox без использования медиа-запросов? Приведите пример.
Для этого можно использовать гибкие размеры элементов, flex-wrap, flex-basis и gap. Например:

.container {
    display: flex;
    flex-wrap: wrap;
    gap: 16px;
}

.item {
    flex: 1 1 260px;
}

При большой ширине элементы могут располагаться в одной строке. Когда свободного места становится недостаточно, flex-wrap переносит их на следующую строку.

10. Какие преимущества дает использование gap вместо margins для создания промежутков между flex-элементами?
gap специально предназначен для создания промежутков между элементами контейнера. Он задаёт расстояние между соседними flex-элементами без необходимости добавлять margin каждому элементу.

Основные преимущества:
- проще читать и поддерживать CSS;
- одинаковый промежуток задаётся одним свойством;
- не требуется учитывать лишний внешний отступ у первого или последнего элемента;
- удобно работает и при переносе элементов на несколько строк;
- можно отдельно задавать row-gap и column-gap.
