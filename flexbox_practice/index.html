Построение layout с помощью Flexbox

Практическая демонстрация основных свойств Flexbox: направления, выравнивания, переноса, размеров элементов, промежутков и изменения порядка.

display: flex

Включает Flexbox для родительского контейнера и делает его прямых потомков flex-элементами.

justify-content

Управляет распределением элементов вдоль главной оси контейнера.

align-items

Выравнивает flex-элементы по поперечной оси.

flex-wrap

Позволяет элементам переноситься на следующую строку при недостатке места.

Основной контент

Боковая панель и основной контент расположены в одну строку с помощью Flexbox. Основной блок занимает оставшееся место.

flex: 1

Адаптивность с Flexbox

Блок 1 flex: 1 1 260px
Блок 2 При уменьшении ширины блоки переносятся.
Блок 3 За перенос отвечает flex-wrap: wrap.

Изменение порядка элементов

Исходный HTML-порядок: 1 → 2 → 3. CSS-свойство order меняет визуальный порядок.

1 - order: 3
2 - order: 1
3 - order: 2
