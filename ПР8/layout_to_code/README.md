### Задача 1.3: Извлечение ключевых данных

**1. Размеры и отступы:**

- Ширина контейнера: `max-width: 1110px; padding: 0 20px;`
- Отступы между секциями: `padding: 120px 0` (стандартный вертикальный отступ)
- Размеры кнопок: `padding: 16px 32px; border-radius: 6px; font-size: 18px;`

**2. Цветовая палитра:**

- Основной цвет: `#ff5545` (акцентный, кнопки, ссылки, активные элементы)
- Дополнительные цвета: `#00e676` (WhatsApp)
- Фоновые цвета: `#ffffff` (основной), `#f7f8fa` (серый для секций)
- Цвет текста: `#000000` (основной), `rgba(0, 0, 0, 0.7)` (второстепенный), `#ffffff` (на темном фоне)

**3. Типографика:**

- Заголовки: Шрифт `Stem` (Bold 700), размеры от 48px до 64px.
- Основной текст: Шрифт `Stem` (Regular 400 / Medium 500), размер 18px, межстрочный интервал 24px.
- Размеры шрифтов: 64px, 48px, 28px, 24px, 18px, 15px, 13px.
- Межстрочные интервалы: `24px` (базовый), `68px` (H1), `1.3` (для подзаголовков).

## Часть 5. Проверка соответствия макету (Отчет)

В ходе выполнения практической работы был проведен детальный анализ макета в Figma, после чего дизайн был успешно перенесен в семантическую HTML-разметку и CSS-стили.

### Соответствует:

- [x] **Цветовая палитра**: Все цвета строго соответствуют макету и вынесены в CSS-переменные (`styles/variables.css`). Основной акцентный цвет — `#ff5545`, фоновые цвета — `#ffffff` и `#f7f8fa`.
- [x] **Типографика**: Шрифт `Stem` подключен локально через `@font-face` в трех начертаниях (Regular 400, Medium 500, Bold 700). Размеры шрифтов, межстрочные интервалы и отступы полностью соответствуют макету.
- [x] **Расположение элементов**: Сетка страницы построена корректно. Для карточек услуг используется `Flexbox`, для блока отзывов — `CSS Grid`, что обеспечивает гибкость и точное позиционирование.
- [x] **Размеры основных блоков**: Ширина контейнера ограничена `1110px`. Hero-секция имеет высоту `798px`, карточки услуг — `350px`, что соответствует замерам в графическом редакторе.
- [x] **Семантическая HTML-разметка**: Использованы правильные теги (`<header>`, `<nav>`, `<section>`, `<footer>`), изображениям заданы корректные атрибуты `alt`. Код валиден и доступен.
- [x] **Чистый и организованный CSS**: Стили разделены на модули:
  - `reset.css` — базовый сброс стилей браузера;
  - `variables.css` — глобальные переменные (цвета, шрифты, тени);
  - `main.css` — стили компонентов и адаптивность.
- [x] **Адаптивность верстки**: В `main.css` добавлены медиа-запросы для разрешений `1024px` (планшеты) и `768px` (мобильные устройства). Сетки перестраиваются, шрифты масштабируются, элементы управления адаптируются под узкие экраны.
