Ответы на вопросы по практической работе 5

1. Какое основное свойство включает CSS Grid и чем принципиально отличается от Flexbox?
Основное свойство - display: grid (или display: inline-grid).
Grid - двумерная система компоновки, позволяет одновременно управлять строками и столбцами. Grid используется для создания сложных макетов страниц.
Flexbox - одномерная система, выстраивает элементы вдоль одной оси. Flexbox - для выравнивания содержимого внутри компонентов (меню, кнопки, карточки).

2. В чем разница между grid-template-columns и grid-auto-columns?
grid-template-columns задаёт явную сетку: количество и размеры колонок, которые разработчик определяет заранее.
grid-auto-columns задаёт размер неявных колонок, которые браузер создаёт автоматически, если grid-элементы размещаются за пределами явной сетки.
grid-template-columns используется, когда структура известна заранее; grid-auto-columns - когда количество элементов неизвестно или динамически меняется.

3. Что делают функции repeat(), minmax() и auto-fit? Приведите примеры.
repeat(n, size) - повторяет трек n раз. Пример: grid-template-columns: repeat(4, 1fr); - четыре равные колонки.
minmax(min, max) - задаёт минимальный и максимальный размер трека. Пример: grid-template-columns: minmax(200px, 1fr); - не меньше 200px, но может растягиваться.
auto-fit - используется с repeat() и minmax(). Создаёт колонки и растягивает их, чтобы заполнить всё пространство; пустые колонки не создаются. Пример: grid-template-columns: repeat(auto-fit, minmax(250px, 1fr));

4. Как работают именованные grid-области и какие преимущества они дают?
Именованные области задаются свойством grid-template-areas у контейнера. Каждая строка - строка сетки, имена обозначают области. Элементы получают grid-area: имя.
Преимущества: наглядность макета, лёгкая перестройка, семантичный HTML, не нужно запоминать номера линий.

5. Объясните систему нумерации grid-линий и как с помощью grid-column и grid-row размещать элементы.
Линии нумеруются с 1: вертикальные - слева направо, горизонтальные - сверху вниз. Если N треков, то линий N+1. Отрицательные номера - отсчёт с конца. Пример: grid-column: 1 / 3; - от первой до третьей линии (2 колонки). grid-row: 2 / 4; - 2 строки. Можно использовать span: grid-column: span 2;

6. Что такое grid-gap (или gap) и чем он лучше margins для создания промежутков в сетке?
gap задаёт расстояние между треками (строками и столбцами).
Преимущества перед margins: не нужно компенсировать отступы у первого/последнего элемента, не влияет на внешние отступы, работает автоматически между всеми элементами, не создаёт двойных отступов на стыках.

7. Как свойства justify-items и align-items влияют на выравнивание grid-элементов?
justify-items - выравнивает содержимое grid-элементов по горизонтали внутри их ячеек.
align-items - по вертикали. Значения: start, end, center, stretch (по умолчанию).

8. В чем разница между auto-fill и auto-fit при создании адаптивных сеток?
auto-fill заполняет строку максимальным количеством колонок, даже если они пустые. auto-fill сохраняет одинаковый размер карточек
auto-fit создаёт колонки и растягивает их, чтобы заполнить всё доступное пространство; пустые колонки не создаются. auto-fit растягивает карточки на всё пространство.

9. Как создать сложные макеты с помощью grid-template-areas и какие правила именования областей существуют?
Нужно задать контейнеру display: grid, определить grid-template-areas, назначить элементам grid-area.
Правила: имена без пробелов, каждая область прямоугольная, нельзя разрывать область на несмежные ячейки, точка (.) обозначает пустую ячейку, количество ячеек в каждой строке одинаковое, одно имя может повторяться в разных строках, образуя единую область.

10. Какие преимущества дает CSS Grid перед другими методами верстки для создания сложных двумерных макетов?
Двумерность (одновременное управление строками и столбцами), гибкость (fr, minmax, auto-fit/fill), точный контроль (линии, области), читаемость (grid-template-areas), меньше кода (не нужны float, clearfix), семантичность HTML, адаптивность, поддержка всеми современными браузерами, комбинируемость с Flexbox.
