Ответы на вопросы по практической работе 3

1. В чем разница между селектором по классу и по ID с точки зрения специфичности и возможности повторного использования?
Селектор по ID (#site-title) имеет специфичность 1,0,0 и должен встречаться на странице только один раз - ID уникален. Его сложно переиспользовать, потому что один и тот же ID нельзя повесить на несколько элементов.

Селектор по классу (.card) имеет специфичность 0,1,0 и может применяться к любому количеству элементов. Классы удобно переиспользовать и комбинировать.

Правило: ID - для уникальных элементов страницы (например, заголовок сайта), классы - для повторяющихся блоков (карточки, кнопки, пункты меню).

2. Как работает каскад в CSS и в каком порядке применяются стили при конфликте правил?
Каскад - это механизм, по которому браузер решает, какое правило применить, когда несколько правил конфликтуют.

Порядок приоритетов (от высшего к низшему):
1) !important - перебивает всё, кроме другого !important с более высокой специфичностью.
2) Специфичность селектора. Считается как три числа (a,b,c):
   - a - количество ID;
   - b - количество классов, атрибутов, псевдоклассов;
   - c - количество тегов и псевдоэлементов.
3) Порядок в файле. Если специфичность равна, применяется то правило, которое объявлено позже.
4) Наследование. Если свойство не задано явно, оно берётся у родителя (для наследуемых свойств).
5) Стили браузера по умолчанию - самый низкий приоритет.

3. Рассчитайте специфичность для селекторов:
   ul li.important
   #site-title
   .content > .featured-post

Специфичность записывается тройкой (a, b, c):
- a - ID;
- b - классы, атрибуты, псевдоклассы;
- c - теги и псевдоэлементы.

1) ul li.important
   ul - тег (c=1)
   li - тег (c=1)
   .important - класс (b=1)
   Итого: (0, 1, 2)

2) #site-title
   ID (a=1)
   Итого: (1, 0, 0)

3) .content > .featured-post
   .content - класс (b=1)
   .featured-post - класс (b=1)
   Итого: (0, 2, 0)


4. Какие свойства в CSS наследуются по умолчанию, а какие нет? Приведите по 3 примера каждого типа.
Наследуемые (типичные для текста):
- color;
- font-family;
- font-size;
- line-height;
- text-align;
- visibility.

Ненаследуемые (относятся к блоку или позиции):
- margin;
- padding;
- border;
- background;
- width и height;
- display;
- position.

5. Как работает селектор > (дочерний селектор) и чем он отличается от селектора потомков (через пробел)?
Дочерний селектор (A > B) выбирает только те элементы B, которые являются прямыми детьми A. Глубже он не спускается.

Селектор потомков (A B) выбирает все элементы B внутри A на любом уровне вложенности.

Дочерний селектор точнее, потомков - шире.

6. Для чего используются псевдоклассы :hover и :nth-child()? В каких практических задачах они могут пригодиться?

:hover срабатывает при наведении курсора. Применяется для:
- подсветки пунктов меню;
- изменения цвета кнопок;
- показа подсказок.

:nth-child() выбирает элемент по его порядковому номеру среди
братьев и сестёр. Применяется для:
- чередования цвета строк таблицы (зебра);
- стилизации каждого третьего или чётного элемента;
- выделения первого/последнего без :first-child / :last-child.

7. Что делает правило !important и почему его следует использовать с осторожностью?
!important повышает приоритет правила до максимального - оно перебивает любые другие правила, кроме другого !important с более высокой специфичностью или объявленного позже.

Использовать с осторожностью, потому что:
- ломает естественный каскад;
- усложняет отладку - непонятно, откуда пришёл стиль;
- мешает переиспользованию компонентов;
- часто сигнал о проблемах архитектуры CSS.

Применять стоит только в крайнем случае: например, для переопределения стилей сторонней библиотеки, которые нельзя изменить.

8. Как псевдоэлементы ::before и ::after расширяют возможности CSS и какой контент они могут содержать?
::before и ::after создают виртуальный элемент до или после содержимого выбранного элемента. В HTML их нет - они существуют только на уровне CSS.

Что можно делать:
- добавлять иконки, стрелки, звёздочки;
- декоративные линии;
- бейджи "new", "sale";
- подсказки.

Что важно: псевдоэлемент обязательно должен иметь свойство content, иначе не отобразится. Содержимое - текст, символ Unicode, картинка через url(), пустая строка "".

9. В каком порядке браузер применяет CSS-правила при одинаковой специфичности селекторов? 
Если специфичность двух правил одинакова, побеждает то, которое объявлено позже в исходном коде (или в подключённом файле, если файлов несколько - учитывается порядок подключения через link).

Пример:
ul li { color: blue; }
li { color: red; }
Здесь ul li (0,0,2) специфичнее, чем li (0,0,1), поэтому синий победит, несмотря на порядок.

Если бы специфичность была равной, победило бы правило, стоящее
ниже.

Также при равной специфичности учитывается источник стилей:
- стили автора;
- стили пользователя;
- стили браузера.
Авторские стили перебивают браузерные по умолчанию.

10. Как инструменты разработчика в браузере помогают анализировать и отлаживать CSS-код?
DevTools (F12) дают:
- вкладку Elements - можно выделить любой элемент и увидеть все применённые к нему правила;
- вкладку Styles - показывает, какие свойства применены, какие зачёркнуты (проиграли по каскаду) и почему;
- панель Computed - итоговые значения свойств после каскада и наследования;
- возможность включать и выключать отдельные правила галочкой в реальном времени;
- редактировать значения прямо в браузере и сразу видеть результат;
- изменять DOM (добавлять/удалять классы), чтобы проверить, как поведут себя селекторы;
- проверять медиа-запросы через режим адаптивности.
