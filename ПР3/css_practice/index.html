Слежение за расписанием

Бот обращается к API сайта колледжа, сравнивает новый снимок расписания с предыдущим и моментально реагирует на любые изменения.

Уведомления об изменениях

Замена преподавателя, смена кабинета, отмена пары или дистант — обо всём этом бот сообщает коротким и понятным текстом.

Массовые изменения

Если изменений слишком много, бот не засыпает чат десятком сообщений, а присылает полное расписание дня или всей недели.

Как это работает

Бот использует два эндпоинта API сайта колледжа: справочники и расписание на дату.

Читать далее о технических деталях

Справочники кэшируются в SQLite на сутки. Расписание проверяется по расписанию окон, сравнивается с предыдущим снимком в базе данных, и при изменениях формируется сообщение, которое отправляется в беседу ВК через Long Poll API.

Команды бота

Команда Описание
/start Приветствие и краткая инструкция

/today Расписание на сегодня
/tomorrow Расписание на завтра
/week Расписание на текущую неделю

О проекте

Проект создан студентами СПК для студентов СПК. Цель — избавить группу от ручной проверки сайта колледжа и сделать так, чтобы об изменениях узнавали все и сразу.
