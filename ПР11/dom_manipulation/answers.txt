Ответы на вопросы по практической работе 11

1. В чем разница между innerHTML и textContent и когда следует использовать каждый метод?
innerHTML возвращает или устанавливает HTML-разметку внутри элемента (включая теги). innerHTML следует использовать, когда нужно вставить форматированный текст с тегами, но это небезопасно (риск XSS-атак), если данные приходят от пользователя.
textContent возвращает или устанавливает только текст, игнорируя HTML-теги. textContent безопаснее и быстрее, используется для простого текста.

2. Как работает делегирование событий (event delegation) и какие преимущества оно даёт при работе с динамическими элементами?
Делегирование событий - приём, при котором обработчик назначается не на сам элемент, а на его родителя. Работает это благодаря всплытию событий (когда событие происходит на дочернем элементе, оно "всплывает" до родителя).
Преимущество: если мы добавляем новые элементы в список динамически, нам не нужно назначать им обработчики - они будут работать благодаря обработчику на родителе. Это экономит память и упрощает код.

3. Какие методы используются для поиска элементов в DOM и в чём разница между getElementById, querySelector и querySelectorAll?
getElementById ищет элемент по его уникальному id (возвращает один элемент).
querySelector ищет первый элемент, подходящий под CSS-селектор (возвращает один элемент или null).
querySelectorAll ищет все элементы по CSS-селектору и возвращает статическую коллекцию (NodeList).

4. Как предотвратить стандартное поведение элемента при обработке событий и когда это необходимо?
Для этого используется метод event.preventDefault(). Это необходимо, например, при обработке отправки формы (чтобы страница не перезагружалась) или при клике на ссылку (чтобы не было перехода по URL).

5. В чём разница между classList.add() и className для работы с CSS классами?
className перезаписывает все классы элемента (если задать новое значение, старые удалятся).
classList - объект с методами (add, remove, toggle, contains), который позволяет добавлять или удалять отдельные классы, не затрагивая остальные. classList удобнее и безопаснее в использовании.

6. Как создать новый элемент и добавить его в DOM несколькими способами? Какой способ наиболее эффективен?
   1) Через document.createElement() (создать) и element.appendChild() (добавить).
   2) Через element.innerHTML = '<div>...</div>' (создаёт и добавляет сразу).
   3) Через element.insertAdjacentHTML(). Наиболее эффективен и безопасен первый способ (createElement), так как он не перерисовывает весь блок и не уязвим к XSS-атакам.

7. Что такое всплытие событий (event bubbling) и как работает метод stopPropagation()?
Всплытие - механизм, при котором событие, произошедшее на дочернем элементе, последовательно вызывается на всех его родителях вверх по дереву DOM.
Метод event.stopPropagation() останавливает это всплытие, и событие больше не передается родительским элементам.

8. Как получить данные из формы и в чём разница между методами сбора form data?
Можно получить данные, обращаясь к каждому полю по id или name (например, document.getElementById('name').value).
Другой способ - использовать объект new FormData(form), который собирает все данные формы.
Разница в том, что FormData удобен для отправки данных на сервер через fetch, а прямое обращение к полям даёт больше контроля при валидации на клиенте.

9. Какие события используются для обработки ввода данных и в чём разница между input, change и keyup?
input срабатывает сразу при каждом изменении значения (даже при вставке из буфера).
change срабатывает только когда элемент теряет фокус (и значение изменилось).
keyup срабатывает при отпускании клавиши на клавиатуре (не работает при вставке мышью).
Для отслеживания ввода в реальном времени лучше всего использовать input.

10. Как оптимизировать производительность при частых манипуляциях с DOM?
   1) Минимизировать количество обращений к DOM (например, собирать все элементы в DocumentFragment, а затем добавлять один раз).
   2) Использовать делегирование событий.
   3) Кэшировать ссылки на элементы в переменные, чтобы не искать их каждый раз.
   4) Избегать использования innerHTML в цикле.
